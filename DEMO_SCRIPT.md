## Live-camera step and explicit fallback

1. Open **Detect Animal**. Check actual detector name/version/labels and the heuristic0.25 cutoff. Explain that this open-vocabulary model shows frequent species confusion and has no labelled independent detector evaluation. A tiger label is a model output, not verified species or individual identity; a score is neither probability nor accuracy.
2. Read the privacy explanation **before** clicking Start camera: JPEG frames go only to this backend, not disk or a third party; no audio/GPS/recording. HTTPS/localhost and browser permission are required. If the embedded preview blocks access, open its secure URL in a separate tab. Browser site settings revoke the grant.
3. Start camera, show Camera on/Stop camera and (after permission) camera selector/rear preference/mirroring. Boxes come only from real backend output. A printed/screen tiger photo can produce a detection; do not claim this proves a live tiger is present. The fake-camera Y4M clip in tests is explicitly a test fixture, not wildlife footage or a simulated production result.
4. Select a returned animal box if several exist. A Person output is ignored and disables capture for the whole frame; no person crop is forwarded. Capturing stops tracks, freezes the selected recent JPEG, shows its temporary crop, re-verifies the box with the local detector and explicitly opens the normal top-five comparison. Identity remains UNKNOWN; no automatic per-frame re-ID.
5. Show detection evidence/score separately from cosine visual-similarity values, absent identity ground truth and human review. Capture/Review exports preserve these distinctions, not images. No labelled detector evaluation has been run; do not present qualitative counts as accuracy.
6. Stop camera or navigate away to release tracks. Tab hiding also stops capture. Live results expire1.2s after capture; no stale box is treated as tracking.
7. **Demo fallback:** if camera, permission or detector fails, switch explicitly to Upload a photo and choose an authorised dataset/source JPG/PNG, then Detect photo. Active input mode is visible. If weights are unavailable, status is Detector unavailable and setup instructions are shown—never a fake box. Original full-frame Compare Tigers still works independently. Pre-cache `python scripts/setup_detector.py` before judging and check `/api/health`; never rely on a download during the demo.
